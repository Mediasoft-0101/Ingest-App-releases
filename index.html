Trước khi cài

Máy nào cũng cần cài VLC trước thì app mới phát được video.

Windows

Nếu Windows hiện "Windows protected your PC", bấm More info rồi chọn Run anyway. Bản mới tự thay thế bản đang cài.

macOS

Kéo app vào Applications. Lần mở đầu tiên macOS sẽ báo "ứng dụng bị hỏng". Tệp không hỏng, chỉ cần mở Terminal và chạy lệnh sau một lần:

xattr -dr com.apple.quarantine /Applications/MediaSoftMediaApp.app

Linux

sudo dpkg -i mediasoft-ingest_*.deb
